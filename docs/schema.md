## Conventions

- Primary keys are `uuid`, generated by the database with `gen_random_uuid()`.
  Foreign keys are `uuid` too, and timestamps are `utc_datetime_usec`.
  `config/config.exs` sets these defaults, so `create table(:name)` adds the
  `id` column. `mix phx.gen.*` output adds its own `id` column and sets
  `autogenerate: true`; replace both.
- Every schema starts with:

      @primary_key {:id, :binary_id, autogenerate: false, read_after_writes: true}
      @foreign_key_type :binary_id
      @timestamps_opts [type: :utc_datetime_usec]

- Soft delete: add a nullable `deleted_at utc_datetime_usec` column. Do not
  hard-delete rows that other tables reference.
- Index naming: `<table>_<col(s)>_index` (Ecto default)
- Foreign key naming: `<referenced_table_singular>_id`
